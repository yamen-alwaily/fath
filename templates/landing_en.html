Quick Start (cURL)

Exchange an authorization code for a Bearer token and query the live account information endpoint:

# 1. Exchange authorization code + PKCE verifier for an access token curl -X POST http://localhost:5001/oauth/token \ -H "Content-Type: application/json" \ -d '{ "grant_type": "authorization_code", "client_id": "sandbox_client_demo", "code": "AUTH_CODE", "code_verifier": "PKCE_VERIFIER" }' # 2. Retrieve authorized bank accounts (AIS) curl -X GET http://localhost:5001/open-banking/v1/accounts \ -H "Authorization: Bearer <ACCESS_TOKEN>"

بنوك سعودية افتراضية

محاكاة متكاملة لـ 3 بنوك افتراضية بأرقام آيبان حقيقية تخضع لخوارزمية التحقق الرسمية MOD-97 مع 8 أشهر من المعاملات.

أمان OAuth 2.0 + PKCE

محرك ترخيص مبني بالكامل بلغة بايثون دون أي مكتبات خارجية. يفرض التحقق من التحدي المشفر S256 والحماية من إعادة الرمز.

بث حي عبر WebSockets

بث لحظي لتحديثات الأرصدة والعمليات المنفذة إلى غرف منعزلة لكل مستخدم مع محاكاة تلقائية للعمليات كل 45 ثانية.

البدء السريع عبر سطر الأوامر

احصل على رمز وصول تجريبي واختبر واجهة معلومات الحسابات فوراً:

# 1. تبادل رمز التفويض مع مفتاح PKCE (Authorization Code Exchange) curl -X POST http://localhost:5001/oauth/token \ -H "Content-Type: application/json" \ -d '{ "grant_type": "authorization_code", "client_id": "sandbox_client_demo", "code": "AUTH_CODE", "code_verifier": "PKCE_VERIFIER" }' # 2. استرجاع قائمة الحسابات المصرفية (AIS) curl -X GET http://localhost:5001/open-banking/v1/accounts \ -H "Authorization: Bearer <ACCESS_TOKEN>"
